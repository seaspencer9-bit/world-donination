# World Domination 🌍

Mobile-first travel tracker for The Spennys.

## Features
- Sam / Lauren / Together country tracking across the official 195 framework
- Bonus territories
- Shared UNESCO World Heritage checklist, refreshed from UNESCO DataHub
- Interactive map
- Trip routes and local photo albums
- Local browser storage plus JSON backup/export
- Installable web app (PWA)

## Publish with GitHub Pages
Upload these files to the repository root. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

Data changes are stored in the browser on that device. Shared sync is a later phase.
